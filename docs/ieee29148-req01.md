# Especificación Comparativa: HU-01 Registro de Productores

## 1. Reescritura bajo estándar ISO/IEC/IEEE 29148:2018
 **ID:** REQ-001
 **Título:** Registro de Productores Agrícolas
 **Descripción:** El sistema deberá proporcionar una interfaz de programación de aplicaciones (API) RESTful que permita la ingesta de datos de perfil de productores agrícolas del Valle del Cauca.
 **Condiciones de Entrada:** El payload JSON debe contener cédula, nombre, municipio (restringido a Dagua y Palmira) y coordenadas geográficas válidas.
 **Comportamiento del Sistema:** El sistema deberá validar que la cédula no exista previamente en la base de datos PostgreSQL. De ser exitoso, persistirá la entidad y retornará `201 Created`. En caso de duplicidad, retornará `400 Bad Request`.
